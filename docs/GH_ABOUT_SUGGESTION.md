Short description:
Research-stage tunable permittivity stack prototypes and modeling tools exploring electromagnetic property control relevant to LQG-related simulations.

Long description:
This repository contains prototype code, data, and modeling tools for researching tunable permittivity stacks. Work focuses on exploratory simulations, prototype demonstrations, and numerical methods for sensitivity and uncertainty quantification. Results are provisional and intended for research audiences; independent validation, provenance tracing, and engineering validation are recommended before interpreting results as production-ready.
